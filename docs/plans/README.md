# Planning and review

Last-Reviewed: 2026-09-25

## Plan-Review Loop

Before creating or changing an implementation plan or spec, read the
[mandatory AI review loop and execution boundaries](../repository-policy.md#review-and-execution-boundaries).
That policy distinguishes ordinary in-scope test maintenance from changes needing Owner
approval; this guide adds no separate execution-approval step.

Create or update the plan in [specs](../../specs/) via [Spec Kit](../../.specify/),
or in this directory.

## Records

- Current feature specifications: [specs](../../specs/).
- Historical implementation plans: this directory and [Superpowers plans](../superpowers/plans/).
- Repository reading routes: [AGENTS.md](../../AGENTS.md) and the [records map](../records/index.md).
