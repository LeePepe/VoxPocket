# 私密模型配置

用户已明确批准：本机 `config.private.json` 保存 Azure 部署和密钥，Git 忽略；仓库只提交空模板。完成后监督 PR 合并、生成 build 并配置/打开 App。

验收：

1. 普通启动时从固定应用沙箱路径读取，不依赖 launcher/env 注入；原环境变量仍可覆盖。
2. 读取先于服务构建，且不阻塞主线程；缺失文件沿用环境配置，无效文件给出脱敏错误并拒绝启动。
3. 私密文件为当前用户所有、0600、排除备份，不出现在 Git 或 App 资源中。
4. 模板不含真实凭据，密钥绝不进日志、错误正文或 UserDefaults。
5. 使用同一 Azure 资源上已验证的语音/精炼部署，不创建新资源、不上传历史录音。
6. 不新增设置页面，不改变识别/精炼请求契约，保留用户已有数据与配置备份。
