# macOS 分阶段模型设置

用户要求：通过设置流程选择不同阶段的模型，语音识别默认选择实时流式，不再依靠改源码切换。

## 交互与范围

- 保留原生 Settings 的快捷键页；「语音与文本」按语音识别、意图分析、语气分析、文本精炼排列。
- 语音识别可选 Azure 实时转写（默认）、Azure 整段转写、Apple Speech；云端录音预览继续使用 Apple Speech。
- 意图、语气、精炼分别选择已接入的 Apple Intelligence 或本机配置的 Azure 文本模型。展示实际配置模型名，不虚构未部署模型列表。
- 保留跳过前置分析开关；跳过时禁用两项分析选择，不能误示为不执行精炼。
- 非敏感选择持久化；已有精炼服务商和跳过分析偏好保留。未保存 ASR 选择时默认流式。
- 可在设置填写实时部署名（安全短标识），用于没有该可选私密配置字段的旧安装。仅部署名作为非敏感偏好保存；endpoint/key 仍只来自获准沙箱配置/环境，不进入设置、UserDefaults 或日志。
- 配置缺失时明确显示实际回退路径，不把「默认选中流式」说成「真实音频验证通过」。已配置的实时路径失败时仍保留整文件兜底。
- 改动在下一次录音应用；进行中的录音/终稿不切换引擎。iOS 不新增设置或启用新默认。

## 验收与分层提交

1. Infrastructure：偏好默认/迁移/合法性；可切换 ASR 的会话隔离及 publisher 稳定；LLM 请求配置快照。独立 SPM 测试及提交。
2. Presentation：设置 ViewModel 的加载、保存、跳过、配置不足提示及浅/深色渲染；设计审查。独立 SPM 测试及提交。
3. App 壳：配置注入、每次录音读取选择、每阶段 provider 路由、启动回归。App 全量构建交 CI。

不新增供应商、不修改密钥、不自动申请麦克风权限或读取用户正文、不改录音历史、不本地构建/安装交付 App。
