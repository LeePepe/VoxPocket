# macOS 设置迁移与主窗口退出

用户确认：把主页面「我的」中的真实设置迁移到独立 Settings，日常使用以 Fn 浮窗为主；保持 SPM + 多 Package。

## 范围与边界

- 仅 macOS：新的原生设置页包含精炼服务商、跳过意图/语气前置分析、两种既有快捷键的编辑/冲突提示/重置、条件性本地模型状态。
- 不迁移静态头像、账户、VAD/保留天数/导出/日志/版本等假配置；不新增热词或私密配置编辑。
- macOS 移除普通主窗口 Scene 和菜单中的主窗口入口；Settings/⌘, 继续打开同一设置窗口。
- 原 F7 等“显示录音面板”仍是兼容性浮动面板，不擅自更改/删除已保存按键；Fn 录音、精炼、粘贴和错误兜底不变。
- 已有历史文件不删除、不迁移 schema；后台存储初始化脱离主窗口，Fn 保存等待同一次初始化完成。
- iOS 代码和兼容性检查保留，不恢复 iOS 开发或发布。

## 分层提交

1. VoxPresentation / UIShared：原生 Settings 内容复用既有 ViewModel 和偏好键；PlatformUI 菜单允许省略旧主窗口入口，保留旧调用兼容，单独 SPM 验证/提交。
2. App 壳：Settings Scene 装配上述内容；移除普通主窗口；存储初始化移到后台生命周期并保持单次加载，单独测试/提交。
3. 不改变 Package.swift、领域模型、UseCase 协议或持久化包。

## 验收

- 原来保存的服务商、分析开关和快捷键加载后保持原值；修改仍写入相同偏好键、发出原通知，重启后保留。
- 设置加载完成前只展示加载状态，不展示或编辑暂态默认值；设置无需创建编辑器、会话或开启录音。
- 配置失败时 Settings 显示原有固定错误说明，退出入口仍可用。
- 新设置可在无主窗口的进程里独立打开/关闭/重复打开；不存在“打开主窗口”菜单项。
- 浅色/深色、加载/冲突/模型状态可读；不增加新的背景色系统。
- 存储初始化并发调用只执行一次；调用者取消不重建存储。数据库打开离开主线程，初始化失败使用固定诊断，不记录用户内容。
- 本地只运行 SPM 与无凭据场景/启动测试，不生成或安装交付 App；完整 App 构建交 CI。
