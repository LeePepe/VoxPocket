# 主 UI 同源的阶段配色

2026-09-09 修订。保持现有精简浮窗的形状、尺寸、文字和录音行为，修复“同色源却不同底材”造成的观感差异。

## 主 UI 依据

- `HomeRecorderView` 与浮窗共同使用 `BackgroundAtmosphere`：随系统外观解析的底色、五个彩色光团、同一材质层，阶段间以约0.9秒交叉过渡。
- 阶段背景颜色来自 `AtmosphereGlass.colors(for:)`；原有按钮文字色另外来自 `Theme`。
- `AtmosphereGlass` 是纯颜色／位置／明暗参数模型；阶段 RGB 不变，底色与染色强度按外观共享。光团在统一坐标画布绘制后映射到窗口比例，窄胶囊也保留完整色彩分布。
- 离屏参考图只用于核对主 UI 背景色库；原生磨砂及模糊效果不一定被快照 API 完整保留，不将参考图当作完整主界面效果。

## 阶段表达

| 阶段 | 主色 | 浮窗表现 |
|---|---|---|
| 待命 | 蓝灰 | 近中性底，弱边缘 |
| 录音 | 青绿 | 真实电平波形，底部柔光随音量轻微提亮 |
| 转写收尾 | 雾蓝 | 克制的忙碌波形，稳定蓝色柔光 |
| 润色 | 薰衣草紫 | 紫色图标与波形，紫色柔光；正文展示真实修改 |
| 完成 | 柔绿 | 绿色确认图标，安定的绿色柔光 |
| 错误 | 珊瑚红 | 红色图标及暖色边缘，保留原文 |

## 画法与节奏

- 不再固定深色底与白字：背景和前景一起跟随系统明暗外观；正文不随录音阶段换色。
- 两种窗口复用同一个背景绘制组件，不仅共用几个 RGB。浅色状态图标保留阶段色相并降低亮度，以满足图形对比度；不增加外投影。
- 细描边、背景色层、图标和波形以共享的900ms节奏过渡；不循环旋转、不伪造处理百分比。
- 浮窗不增加连续刷新时间轴；电平事件控制录音态的轻微呼吸，不改变窗口布局。主背景连续刷新仅用于录音态的电平弹簧，其余状态暂停。
- 首次文字区展开为240ms，文字延后180ms后用120ms淡入；后续试用新增420ms顶部点状入场。阶段色变化不改变480×148pt展开包络。
- 减少动态效果：关闭阶段动画和音量呼吸。降低透明度／增强对比度：关闭装饰柔光，保留实色底和语义状态；增强对比度使用实色描边。
- 主 UI 实际阶段色优先于通用模板的默认 seed 配色；不把另一套蓝／青／紫映射当成品牌新主题。

## 验证边界

使用模拟文字和真实 SwiftUI 组件验证相同阶段与外观的背景像素、两种明暗模式的正文与图标对比度、状态切换与摄像头透明区。设计评审输出仅保留在本地，不作为仓库合并凭据；本轮提交独立 PR 并监督合并，合并后创建本地 build，安装另行授权。两套录音业务状态仍独立，不为视觉一致性伪造或同步录音状态。
