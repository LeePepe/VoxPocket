# 主 UI 同源的阶段配色

2026-09-08。保持现有精简浮窗的形状、尺寸、文字和录音行为，只调整色彩表达。

## 主 UI 依据

- `HomeRecorderView` 使用 `BackgroundAtmosphere`：近白底、五个彩色光团、磨砂层，阶段间以约0.9秒交叉过渡。
- 阶段背景颜色来自 `AtmosphereGlass.colors(for:)`；原有按钮文字色另外来自 `Theme`。
- `AtmosphereGlass` 是纯颜色／位置模型，本次移到 `UIShared/DesignSystem` 作为主 UI 与浮窗的共同色源；颜色数值、主 UI 布局及背景画法不变。
- 离屏参考图只用于核对主 UI 背景色库；原生磨砂及模糊效果不一定被快照 API 完整保留，不将参考图当作完整主界面效果。

## 阶段表达

| 阶段 | 主色 | 浮窗表现 |
|---|---|---|
| 待命 | 蓝灰 | 近中性底，弱边缘 |
| 录音 | 青绿 | 真实电平波形，底部柔光随音量轻微提亮 |
| 转写收尾 | 雾蓝 | 克制的忙碌波形，稳定蓝色柔光 |
| 润色 | 薰衣草紫 | 紫色图标与波形，紫色柔光；正文展示真实修改 |
| 完成 | 柔绿 | 绿色确认图标，安定的绿色柔光 |
| 错误 | 珊瑚红 | 红色图标及暖色边缘，保留原文 |

## 画法与节奏

- 深色基底与白色文字不随阶段变化，图标直接使用主 UI 的阶段主色；装饰色层随阶段变化。
- 取主 UI 左上、色心、右上三种颜色，形成低强度的上沿染色与下沿柔光；不增加外投影。
- 细描边和背景色层以720ms交叉淡入淡出，图标与波形采用相同节奏；不循环旋转、不伪造处理百分比。
- 不增加新的连续时间轴；音量只改变录音态底部柔光的不透明度，不拉伸窗口。
- 首次文字区展开为240ms，文字延后180ms后用120ms淡入；后续试用新增420ms顶部点状入场。阶段色变化不改变480×148pt展开包络。
- 减少动态效果：关闭阶段动画和音量呼吸。降低透明度／增强对比度：关闭装饰柔光，保留实色底和语义状态；增强对比度使用实色描边。
- 主 UI 实际阶段色优先于通用模板的默认 seed 配色；不把另一套蓝／青／紫映射当成品牌新主题。

## 验证边界

使用模拟文字和真实 SwiftUI 组件验证色源、正文对比度、状态切换与摄像头透明区。设计评审输出仅保留在本地，不作为仓库合并凭据；后续按用户要求随贴顶与预热修复提交 PR 并安装。
