# Feature Specification: Fn 实时转写「声音落岛」

**Feature Branch**: 沿用当前工作分支（本任务不提交或发布）

**Created**: 2026-09-08

**Status**: Approved — 独立设计稿已获用户批准实施

**Input**: User description: "重新设计Fn按下后的浮窗view，需求：要展示识别到的文字内容。要和灵动岛结合。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 说话时看见文字 (Priority: P1)

用户按住 Fn 说话，在屏幕顶部的灵动岛风格浮窗中看见实时识别内容，不离开正在输入的应用。

**Why this priority**: 让用户直接确认语音是否被正确识别。

**Independent Test**: 按住 Fn，逐步说出两句中文，观察文字随识别结果更新。

**Acceptance Scenarios**:

1. **Given** 尚无识别文字，**When** 开始录音，**Then** 显示紧凑黑色胶囊、录音状态和音量波形。
2. **Given** 正在录音，**When** 收到文字，**Then** 同一个岛展开，状态栏下面显示识别文字。
3. **Given** 文字超过可视区域，**When** 新内容到达，**Then** 显示最新文字，岛不无限增高，旧内容可滚动查看。

### User Story 2 - 松开后跟踪处理 (Priority: P2)

用户松开 Fn 后仍能看到识别结果和当前处理阶段。

**Why this priority**: 防止用户把正在处理误认为转写丢失。

**Independent Test**: 分别检查转写、润色、错误、完成状态的展示。

**Acceptance Scenarios**:

1. **Given** 已有文字，**When** 松开 Fn 进入转写或润色，**Then** 保留识别原文，状态栏说明处理阶段。
2. **Given** 录音失败，**When** 显示错误状态，**Then** 显示可读的重试提示，不只靠颜色。
3. **Given** 上一轮有文字，**When** 新一轮录音开始，**Then** 不显示上次文字。

### Edge Cases

- 空字符串或纯空白不展开文字区。
- 长中文、英文和多行文本可换行、滚动，不越出浮窗。
- 待命状态隐藏旧文本；完成与错误状态显示简短标签。
- 开启减少动态效果后关闭形变动画；辅助技术可读取识别原文。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 浮窗必须直接显示录音中收到的识别原文，转写和润色阶段继续展示原文。
- **FR-002**: 浮窗必须采用已批准的「声音落岛」：有刘海屏幕从上沿一体展开，避开真实摄像头区域，两翼放状态与波形；无刘海屏幕显示顶部独立胶囊。
- **FR-003**: 状态栏必须包含可读阶段标签；录音时显示音量波形，处理时显示忙碌反馈。
- **FR-004**: 长文本必须限制可视高度，自动跟随最新内容；用户向上滚动时暂停跟随，回到底部后恢复。
- **FR-005**: 必须保留 Fn 按下开始、抬起结束与既有粘贴流程，不抢输入焦点。
- **FR-006**: 展示不得新增文字日志、遥测或持久化；辅助技术可访问文字，减少动态效果设置被尊重。
- **FR-007**: 错误状态保留已有识别原文并允许复制，错误提示不替换原文；新一轮录音清空旧文字。
- **FR-008**: 所有屏幕上岛体、正文和操作栏均在可用边界内；不能绘制虚假的硬件刘海。

### Key Entities

- **识别原文**: 当前录音的累积识别结果；不与润色中的输出交替替换。
- **录音阶段**: 待命、录音、转写、润色、完成和错误。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 录音、转写、润色三个阶段，有文字时均可见原文。
- **SC-002**: 所有六个状态的内容均限制在浮窗范围内；500 字测试文本仍能看到最新结尾并滚动查看开头。
- **SC-003**: 连续两次录音，新一轮初始界面不显示上一轮文字。
- **SC-004**: 所有状态有可读标签，识别文字可通过辅助技术读取。

## Assumptions

- 视觉基准为 [独立设计稿](prototype-independent/DESIGN.md) 与其 preview-live.png；替代首版独立悬浮卡片方向，不调用 iPhone 系统灵动岛。
- 复用已有识别数据流、快捷键和浮窗生命周期，不改变识别引擎、润色策略、自动关闭时机或粘贴行为。
- 本次展示识别原文；润色只改变状态标签，避免处理中的不完整润色覆盖原文。
- 原型中的模拟按键、手动插入等演示控件不直接迁入产品；正式版保留 Fn 按下开始、松开结束和自动粘贴。浮窗提供鼠标结束／取消操作，不显示尚未支持的全局 Esc 提示。
- 实现范围为展示层及 app 壳的屏幕定位接线，不更改下层识别或润色服务。
