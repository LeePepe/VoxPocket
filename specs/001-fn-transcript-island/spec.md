# Feature Specification: Fn 实时转写「声音落岛」

**Feature Branch**: `feat/island-phase-colors`（按用户要求提交 PR 并安装本地验证）

**Created**: 2026-09-08

**Status**: Revised — 根据本地试用反馈精简状态展示与展开动画

**Input**: User description: "重新设计Fn按下后的浮窗view，需求：要展示识别到的文字内容。要和灵动岛结合。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 说话时看见文字 (Priority: P1)

用户按住 Fn 说话，在屏幕顶部的灵动岛风格浮窗中看见实时识别内容，不离开正在输入的应用。

**Why this priority**: 让用户直接确认语音是否被正确识别。

**Independent Test**: 按住 Fn，逐步说出两句中文，观察文字随识别结果更新。

**Acceptance Scenarios**:

1. **Given** 尚无识别文字，**When** 开始录音，**Then** 显示紧凑黑色胶囊、录音状态和音量波形。
2. **Given** 正在录音，**When** 收到文字，**Then** 同一个岛展开，状态栏下面显示识别文字。
3. **Given** 文字超过可视区域，**When** 新内容到达，**Then** 显示最新文字，岛不无限增高，旧内容可滚动查看。

### User Story 2 - 松开后跟踪处理 (Priority: P2)

用户松开 Fn 后仍能看到识别结果和当前处理阶段。

**Why this priority**: 防止用户把正在处理误认为转写丢失。

**Independent Test**: 分别检查转写、润色、错误、完成状态的展示。

**Acceptance Scenarios**:

1. **Given** 已有文字，**When** 松开 Fn 进入转写或润色，**Then** 保留原文直到润色结果返回，再显示真实修改内容，以状态色表示阶段。
2. **Given** 录音失败，**When** 显示错误状态，**Then** 保留原文，以红色与错误图标提示，右键提供复制和关闭操作。
3. **Given** 上一轮有文字，**When** 新一轮录音开始，**Then** 不显示上次文字。

### Edge Cases

- 空字符串或纯空白不展开文字区。
- 长中文、英文和多行文本可换行、滚动，不越出浮窗。
- 待命状态隐藏旧文本；完成与错误状态使用颜色及简短图标，辅助技术可读出状态。
- 录音中收到增量润色结果不能阻止松开 Fn 结束录音。
- 展开后原文或润色文字长度变化不再改变岛体尺寸。
- 开启减少动态效果后关闭形变动画；辅助技术可读取识别原文。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 浮窗录音时显示原文；润色时显示实际返回的修改内容，没有润色结果时保留原文，失败时可复制原文。
- **FR-002**: 浮窗必须采用已批准的「声音落岛」：有刘海屏幕从上沿一体展开，避开真实摄像头区域，两翼放状态与波形；无刘海屏幕显示顶部独立胶囊。
- **FR-003**: 常态界面只保留文字、轻量图标与波形；阶段色与主 UI 同源，以青绿／蓝／薰衣草紫／柔绿／珊瑚红表达录音／转写收尾／润色／完成／错误，不常驻状态文案、计时、说明或操作栏。辅助技术仍能读取阶段。
- **FR-004**: 长文本必须限制可视高度，自动跟随最新内容；用户向上滚动时暂停跟随，回到底部后恢复。
- **FR-005**: 必须保留 Fn 按下开始、抬起结束与既有粘贴流程，不抢输入焦点。
- **FR-006**: 展示不得新增文字日志、遥测或持久化；辅助技术可访问文字，减少动态效果设置被尊重。
- **FR-007**: 错误状态保留已有识别原文并允许复制，错误提示不替换原文；新一轮录音清空旧文字。
- **FR-008**: 所有屏幕上岛体、正文和悬停按钮均在可用边界内；不能绘制虚假的硬件刘海。
- **FR-009**: 首次有文字时一次无回弹展开；后续识别、换行及润色更新不能引起反复伸缩，文字本身不参与形变。
- **FR-010**: 阶段变化时，图标、波形、柔和背景染色及细边缘平滑过渡，不改变文字颜色和布局，不用旋转彩环或虚假进度。减少动态效果时关闭色彩过渡，降低透明度或增强对比度时使用实色底。
- **FR-011**: 浮窗每次出现时从顶部中心的 8pt 圆点向两侧、向下揭开，约 0.42 秒，无回弹；有刘海时起点位于真实摄像头下缘。文字不参与缩放，展开后淡入；阶段变化不重播入场，减少动态效果时直接呈现完整岛体。
- **FR-012**: 刘海贴顶浮窗在 AppKit 显示及位置约束后仍保持屏幕顶边，不被推到菜单栏下方；非贴顶、无刘海、越界或不匹配的窗口继续接受系统边界约束。
- **FR-013**: 启动后延迟、低优先级预热空浮窗；预热不创建录音会话、不访问用户文本、不显示窗口或抢焦点。若用户先按 Fn，取消尚未执行的预热，不延迟用户操作。

### Key Entities

- **识别原文**: 当前录音的累积识别结果，录音时展示并保留作失败兜底。
- **润色结果**: 现有后处理流程实际返回的文本；只在润色和完成阶段展示，不伪造进度或逐字动画。
- **录音阶段**: 待命、录音、转写、润色、完成和错误。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 录音、转写、润色三个阶段，有结果时均可见文字；润色结果返回后无需等完成即可看到修改。
- **SC-002**: 所有六个状态的内容均限制在浮窗范围内；500 字测试文本仍能看到最新结尾并滚动查看开头。
- **SC-003**: 连续两次录音，新一轮初始界面不显示上一轮文字。
- **SC-004**: 所有状态有不同的视觉信号及辅助技术标签；无文字状态的截图不含常驻说明或计时。
- **SC-005**: 同一段识别内容从一行增长为长文时，只发生首次展开，不发生后续尺寸变化。
- **SC-006**: 录音、转写、润色、完成、错误的浮窗阶段色与主 UI 对应色库一致，正文在最强背景染色下仍满足4.5:1对比度目标。

## Assumptions

- 视觉基准为 [独立设计稿](prototype-independent/DESIGN.md) 与其 preview-live.png；替代首版独立悬浮卡片方向，不调用 iPhone 系统灵动岛。
- 复用已有识别数据流、快捷键和浮窗生命周期，不改变识别引擎、润色策略、自动关闭时机或粘贴行为。
- 本次按用户反馈展示实际润色过程；润色服务及其回退策略不变，不为展示效果制造延迟或进度。
- 原型中的模拟按键、手动插入等演示控件不直接迁入产品；正式版保留 Fn 按下开始、松开结束和自动粘贴。浮窗提供鼠标结束／取消操作，不显示尚未支持的全局 Esc 提示。
- 实现范围为展示层及 app 壳的屏幕定位接线，不更改下层识别或润色服务。
- 本轮修改展示层与 app 壳的浮窗接线；用户的精简与颜色优先要求覆盖通用设计技能中的常驻标签及多层文字建议。
