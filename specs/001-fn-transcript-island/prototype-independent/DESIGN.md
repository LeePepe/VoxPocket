# VoxPocket · 声音落岛

独立概念设计，面向 macOS 原生 SwiftUI 实现方向。此 HTML 是可操作的视觉示意，并未集成到 VoxPocket，也未访问真实麦克风。

## 独立性与输入

只读取用户指定的 my-designer 技能、通用设计语言与原始色彩模板，以及项目 constitution；未读取项目现有实现、spec、设计文档或截图。概念稿仅在本临时目录生成，演示文案为虚构预设，不读取用户内容。

## 设计决定

- **岛是入口，也是文字的容器。** 展开态从屏幕上沿生长，而不是在刘海下面另挂一张卡片。顶部中间 168 × 30 的区域留给摄像头/刘海，不放交互与文字。状态和音量分布两翼，正文在安全区下方。
- **文字优先。** 实时文字 22px / 1.7 行高；确认的前文保持主文字色，最新片段使用唯一 blue 主色。没有同时排列“原文”和“润色稿”，避免视觉竞争。
- **操作延后。** 聆听时只有结束与取消提示。完成后才出现插入与复制；插入须用户确认，不自动覆盖工作内容。此预览仅插入页面内的模拟文稿。
- **形态随内容展开。** 等待态较窄；识别态宽 560px；长文本在固定最大阅读高度内滚动，浮窗不无限向下侵占工作区。
- **颜色不是新的皮肤。** 原样复制 my-designer 的 color-system.ts，经 bun 转译使用；blue + slate，固定 Apple 语义绿红。采用亮度层级与 1px 边界，不加投影。半透明与模糊提示原生玻璃材质，但不伪装为已实现的 Liquid Glass。
- **动效只说明状态。** 宽度过渡 350ms；演示时波形轻微律动，文字分句到达；处理态波形呼吸。尊重系统减少动态效果。默认静态实时态方便观看，不强迫自动播放。

## 操作

直接本地打开 `index.html`，无需服务器、联网或安装依赖。颜色 JS 已随附。

- 底部切换：等待 / 实时文字 / 处理 / 完成 / 错误。
- 点击模拟 Fn，或空格键：开始 → 结束 → 确认文字。浏览器通常不暴露真实 Fn，因此不声称能捕获 Fn。
- Esc：收起至等待形态。
- 长文本：开启/关闭可滚动样本。
- 播放演示：等待 → 分句显示 → 处理 → 完成，可暂停。
- 完成 → 插入模拟文稿：仅改变本页右侧的虚构笔记。
- 复制文字：显式点击才写剪贴板；浏览器不允许时选中文字并提示 ⌘C。

## 原生实现注意点

须由 SwiftUI / AppKit 根据实际屏幕刘海、安全区、屏幕缩放和外接无刘海显示器计算位置；网页画框不是系统几何测量。没有刘海时保留顶部居中的独立胶囊入口，不制造虚假硬件遮挡。Fn 监听、跨应用文字写入、权限和真实转写生命周期均不在本概念范围。

- Esc 收起与空格模拟 Fn。

- `cmp` 校验原始 `color-system.ts` 与技能源完全一致。
