# 本地试用反馈：精简浮窗与润色可见性

日期：2026-09-08。已按用户要求完成本地签名构建，并替换安装至 `/Applications/VoxPocket.app`；旧版完整备份，用户会话与设置保留。未推送或发布 TestFlight。

## 已确认的原因

1. 后处理流程没有移除：快捷录音仍连接流式协调器和润色 UseCase。但此前 `displayedTranscription` 在润色期间只返回原文，直到 done 才返回修改结果。
2. 录音中的增量润色结果曾将 UI 状态提前切成 refining；停止方法只接受 listening，导致这条路径下 Fn 松开停止被忽略。两个发布者现在仅在录音停止后的处理阶段改变 UI 状态。
3. 旧布局按文字测量高度不断改变展开尺寸，且文字继承外层形变时可能在首帧被窄边界裁切。

以上均用人工构造的 fixture 复现；没有读取用户录音或记录识别内容。不据此声称用户某次真实模型调用一定成功。

## 当前设计与行为

- 常态只保留白色文字、轻量图标与波形；移除状态词、计时、说明及常驻操作栏。
- 状态色：蓝录音、青转写收尾、紫润色、绿完成、红错误；图标形状和辅助功能标签仍表达阶段。
- 展开包络480×148pt，阅读区80pt；首次有文字时无回弹展开，后续文字变长或润色不再改变岛体大小。
- 240ms轮廓过渡，文字延后180ms后用120ms淡入；不对实际润色结果加人为逐字输出或业务延迟。
- 润色结果返回后即可见修改；空结果保留原文，出错仍可复制原文。
- 悬停出现取消／关闭按钮，右键与辅助功能动作提供结束、取消、复制和关闭。
- 依照用户本次要求，颜色优先与精简内容覆盖通用设计技能中的常驻状态标签、三级文字层级建议。
